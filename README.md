# AI Quality Inspector

Sistema inteligente de controle de qualidade de produtos utilizando Machine Learning e Visão Computacional.

## 🎯 Objetivo

O AI Quality Inspector tem como objetivo analisar dados e imagens de produtos para identificar possíveis problemas de qualidade e auxiliar na decisão sobre quais itens precisam de revisão.

## 🧠 Inteligência Artificial

O projeto será desenvolvido progressivamente utilizando:

- análise e preparação de dados;
- Machine Learning para classificação de risco;
- Visão Computacional para análise de imagens;
- combinação dos resultados dos modelos.

## 🏗️ Arquitetura

O projeto será composto por:

- **Frontend:** React + TypeScript
- **Backend:** Python + FastAPI
- **Machine Learning:** Pandas + Scikit-learn
- **Visão Computacional:** CNN
